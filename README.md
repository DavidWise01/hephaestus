Open `PROMETHEUS.html` in any browser. No server needed.

**Left panel (HEPHAESTUS forge):**

- Set value (USD at issue)  
- Click **⬥ Flay Target** to run the engine
- Or load a **PALAMEDES test vector** (V1–V5)
